## 1. 范围与使用边界

本参考限定为 TAYRON（探岳）2019 起、发动机代码 DKVB 的冷却系统密封性检查及冷却液膨胀壶密封盖安全阀检查。依据为 S02 第 1 页车型对应表与 S01 所在维修章节；不是按父目录名称推断所有车型通用。[S02-P1]

- 不扩展至 DPLA、DKXA、GTE 混动或其他发动机。S02 将 DPLA 对应到 TAYRON X 2020 起等车型，不能因共用文件夹就混用。
- “2019 起”为来源车型系列标识，不代表已核实每辆车、每个零件修订或全部后续年款。真实车辆仍须核对发动机代码、车辆资料与维修资料版本。
- 本文不覆盖过热全部原因、水泵和节温器功能诊断、传感器电气诊断、故障码定位、冷却液更换和零件拆装。
- 本文仅给出来源支持的检查关系，不预设完整维修树，不声称可自动诊断真实车辆。
- 本文未混入培训书的案例读数、手写批注或其他车型数值。

后文使用三个明确标签：**来源事实**表示原页面支持的内容；**整理约束**表示为防止系统过度推断制定的测试要求；**待核实**表示来源不足，不能由模型补全。

## 3. 检查对象与前置条件

### 3.1 两个不同检查对象

| 编号 | 对象 | 本次测量 | 不得混用 |
|---|---|---|---|
| OBJ-SYSTEM | 冷却系统，检测仪通过对应接头连接膨胀壶 | 建立测试过压后记录一定时间内的压力下降 | 不用壶盖安全阀开启压力判定系统保压 |
| OBJ-CAP | 冷却液膨胀壶密封盖中的安全阀 | 检测阀在规定过压范围是否打开 | 不用系统允许压降判定壶盖开启压力 |

对象与连接方式来自 S01-P5、S01-P6；禁止混用为整理约束。

### 3.2 安全与条件

**来源事实：[S01-P5]**

- 系统密封性检查的工作步骤以发动机已达到工作温度为前提。
- 暖机状态的冷却系统存在过压，高温蒸汽和冷却液可能造成烫伤。
- 原文要求防护手套、防护眼镜，并在解除过压时以布覆盖密封盖、小心操作。
- 原文提示温度下降会影响压力下降量；发动机越冷，压力下降越小，必要时在冷机状态重复检查。

**整理约束：** 对话系统须先识别上述风险与条件。本文不是供未经训练人员照抄操作的现场指令；不能仅为满足“暖机”条件而提示直接打开高温带压壶盖。

**待核实：** 本节没有给出“工作温度”的具体摄氏度、检查时发动机运行/停止状态、约 1.5 bar 的允许偏差、仪器精度和完整冷机复测规范。不得补写为已经来源验证的数值或状态。

### 3.3 工具

S01-P5 列出冷却系统检测仪及两种接头；S01-P6 配图给出壶盖连接方式：

- 检测仪：F.V.G 1274 B / V.A.G 1274 B（图中亦见 FVG1274BG 标记）。
- 系统连接接头：F.V.G 1274/8T / V.A.G 1274/8。
- 壶盖连接接头：F.V.G 1274/9T / V.A.G 1274/9。

工具替代品适配、校准和连接密封性未由本文验证。仪器或连接异常时不能把读数直接归因为车辆部件故障。

## 4. 可追溯规格

### SPEC-SYSTEM-01：系统测试起始过压

- 对象：OBJ-SYSTEM。
- 来源数值：约 **1.5 bar**。
- 压力类型：过压，不能与绝对压力混为一谈。
- 来源：S01-P5，工作步骤中检测仪手动泵建立过压处。
- 条件：按来源工具、连接和检查条件执行。
- 待核实：原文未给“约”的数值公差；项目不能自行设定一个已认证的容差区间。

### SPEC-SYSTEM-02：系统保压观察

- 对象：OBJ-SYSTEM。
- 来源观察时间：**10 分钟**。
- 来源压力下降界限：**0.2 bar**。
- 原文关键措辞：“不允许压力在 10 分钟内下降 0.2 bar 以上”；随后要求此类下降时查明泄漏部位并排除故障。[S01-P5]
- 原文同时说明冷却液温度会影响压降，必要时冷机重复检查。[S01-P5]
- 整理约束：不能只保留一个阈值而删除温度、时间、起始过压和检查对象。
- 临界语义待核实：“以上”在严格数值规则中可含等号，但页面温度提示又使用 0.2 bar 描述压降；本文不把恰好 0.2 bar 自动判为通过，也不直接据此确定泄漏。该点应提示临界待核实或复测，待专业审核明确比较关系。

### SPEC-CAP-01：壶盖安全阀开启

- 对象：OBJ-CAP。
- 来源开启过压范围：**1.6 至 1.8 bar**。[S01-P5]
- 观察内容：安全阀是否在该范围内打开。
- 来源后续：安全阀没有打开时，更换密封盖。[S01-P6]
- 整理约束：该动作须以壶盖专门检测和可靠观测为依据，不能由系统保压异常直接触发。
- 待核实：页面没有单独说明提前开启、仪表不确定度或边界舍入处理；这些情况不能套用“未打开”结论。记录异常并请求进一步核对，也不能继续无限加压。

## 5. 记录测量时必须保留的信息

以下为整理设计的记录要求，不是声称原手册定义了这些软件字段。

| 信息 | 用途 |
|---|---|
| 车型、发动机代码、适用性核对情况 | 防止跨车型套用 |
| 检查对象（系统或壶盖） | 选择正确规格 |
| 工具与连接、是否存在仪器/接头异常 | 判断读数可信度 |
| 温度状态及观察期间温度变化 | 保留原文的干扰因素 |
| 压力类型、单位、起始读数、结束读数 | 计算同一检查的压降 |
| 实际观察时长 | 防止将短时读数冒充 10 分钟结果 |
| 壶盖阀门开启状态与对应压力 | 支持壶盖专项判断 |
| 观察到的泄漏位置或尚未找到的位置 | 区分系统异常与具体部件定位 |
| 同一次检查的时间和记录关联 | 防止拼接不同次检查形成伪冲突 |

压降计算为同一次检查的起始过压减结束过压，二者需采用一致单位。该计算是整理说明；不允许把负压降取绝对值、将温度不同的记录随意拼接或把短时数据线性外推成 10 分钟结论。

## 6. 有界判断与建议

下表是来源事实之上的保守决策整理，不是从原文复制的完整诊断树。

| 编号 | 已有证据 | 可以表达的判断及下一步 | 不得表达 |
|---|---|---|---|
| DEC-01 | 发动机代码未知或不匹配 | 本参考适用性未确认；先核对车辆身份或寻找对应资料 | 直接使用 DKVB 数值 |
| DEC-02 | 时间、压力类型、单位、起始压力或对象缺失 | 条件不足；补充本次检查记录 | 合格、故障已确认 |
| DEC-03 | 系统按来源条件检查，10 分钟内压降明显超过 0.2 bar | 触发查漏方向；结合温度变化、仪器与连接情况判断是否需要复测，继续定位泄漏。[S01-P5] | 水泵损坏、节温器损坏、缸垫损坏或某特定零件必须更换 |
| DEC-04 | 系统条件完整、10 分钟观察完成，压降低于 0.2 bar | 本次记录未触发本文的压降异常界限；结论限定为此项检查 | 整个冷却系统正常、全部泄漏永久排除、发动机不会过热 |
| DEC-05 | 恰好 0.2 bar 或读数精度无法区分临界值 | 标记临界待核实；保留原文并请求复核或复测 | 自动合格、自动确定泄漏 |
| DEC-06 | 观察期温度变化可能影响结果 | 说明温度干扰；原文支持必要时冷机复测，冷机细节不得编造。[S01-P5] | 把压降全部归因于正常降温或全部归因于泄漏 |
| DEC-07 | 壶盖专门测试中，安全阀在来源范围打开 | 本次开启表现与来源范围相符 | 系统保压通过、壶盖所有功能均正常 |
| DEC-08 | 壶盖专门测试可靠确认安全阀在来源规定条件下未打开 | 原文支持更换密封盖方向；执行前由人员核对检测有效性。[S01-P6] | 仅因低于开启范围时未打开就要求更换 |
| DEC-09 | 壶盖提前开启、记录矛盾或工具状态不明 | 与预期不符或证据不足，进一步核对；保留来源缺项 | 套用未开启规则、编造允许范围 |

系统应能表示“资料支持继续检查，但尚不能定位”，不能为了输出确定结论而虚构缺失证据。异常检测、部件定位、维修动作、维修后验证是不同结论层级。
