# 匹配区域的语义排序（待体验）

本轮只在车辆/故障码关系表已选出的模板区域内调整先查顺序。AI 输入为已保存主诉、故障码、症状工况，以及各候选区域的名称和简短职责；不发送完整维修资料、题目选项或观察记录。模型需返回候选区域 ID 的完整排列和每区一句理由。若遗漏、增加或重复区域，排序失败并显示原模板顺序；排序不创建检查事实，也不改变模板、分组、问题或选项。

区域卡片保留既有样式。只有完成真实排序时，位置和“建议优先级”随结果调整；病例的观察保存和其他区域仍可独立使用。失败或请求状态未知时不会自动再次调用。结果单独存于 `case_area_rankings`，同一病例最多一次模型尝试。

当前 WP15 实例保持非付费模式，未请求真实模型。要在单独授权后为指定病例开放一次真实排序，先停止本项目实例，再以 `scripts.wp15_workbench start --area-ranking-real-once-case <case_id>` 启动；启动器只为该病例临时注入项目配置的 DeepSeek 密钥，分析模块仍保持 stub。页面点“用 AI 排序区域”才会发出一次请求。体验后停止并正常启动即可关闭窗口。勿把模型排序理解为确诊或已完成排查。
