# ADR-0001：候选范围与证据准入

日期：2026-09-18。状态：PROPOSED_FOR_REVIEW（WP-00 已落实隔离边界，真实车型范围未获用户/专家确认）。

下一版候选方向为一个资料齐全的发动机冷却系统。当前 SRC-001 仅提供 EA888 Gen3/N493 整理线索，缺车型、年款、精确发动机代码、可核对原件及授权，因此不能宣布支持 EA888 全系或任一具体车辆。**当前已确认真实维修范围为零**。

SRC-002—005 是明确合成/虚构样例；仅可作为后续隔离回归素材，不得进入正式检索或维修证据。SRC-001 的合成属性未知，不能因为文件名含 sample 就认定虚构，也不能因正文像手册而认定权威。SRC-006—007 为合成稿链接的外部图片，来源与内容未审，不能支持真实位置/电路判断。

程序约束状态、权限、引用、适配与数值校验；候选区域和检查路径将由资料与观察驱动。固定树不作为真实模式兜底。本包代码迁移为零，只记录可复用思路。架构沿用总指南，依赖锁和技术探针留 WP-01。

允许独立推进通用基础，不假装真实诊断效果资格已满足。由用户/资料提供者确认合法来源和使用许可、车型/年份/发动机代码；维修专业审核者核对原章节及规格。正式资料最迟 WP-10/真实效果验收前补齐；模型契约最迟 WP-09 收口。无人被虚构为已审核者。

结果：保留 unknown，限制当前宣称范围；补章清单见 data-readiness.md。检索真值集尚未建立，Recall@5≥0.85 仍是规划目标，没有冻结或达到实测指标。任何后续带缺项继续须单独明确授权。
