## 你会体验到什么

本节包含病例预告，README仅供用户／开发者阅读，不进入检索，也不整篇作为诊断模型上下文。

客户说：“低负荷还行，加速、上坡时无力，偶发故障灯，重启后暂时好转。”系统确认车辆和P0299记录后，先核对压力读数是否可信，再确认模拟负荷下的增压不足。

主病例A会发现一处增压空气接头泄漏。完成模拟修复后，压力跟随改善但仍不满足演示标准，因此继续检查V465调节机构与引导调整状态。完成第二项模拟处理后，再验证压力、症状和故障码记录。只有用户选择生成报告，才输出本次演示总结。

这不是每辆车都走同一条路线：病例B在管路修复后结束；病例C不经换管路直接转控制方向；病例D先发现测量可信度问题；病例E要求补充身份和压力类型；病例F最终仍不能定位，交接继续检查。
