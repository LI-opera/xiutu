# 增压压力测量检查与维修参考｜详细版


> 本次修订：2026-09-26，补充操作方法、结果分支与修后确认；新增内容为本地资料和公开技术资料的综合整理，不将其他车型参数作为本车标准。
适用对象：2019 年探岳、DKVB 发动机对应的增压压力测量区域。  
关联问题：PRS-01—PRS-12。  
资料版本：PRESSURE-REFERENCE-1.1；整理日期：2026-09-26。

本资料解决三个实际问题：**压力数据能不能信、压力变化说明什么、确认测量链路故障后怎样处理。** 它把当前问题选项、G31/G71 的车型资料及通用电气诊断方法组织成可顺序执行的参考，而不是把“压力低”直接等同于“涡轮损坏”。

车型拆装要求以文中注明的 DKVB 部位为限；电路测量须先确认实车端子功能。本文没有把通用传感器的针脚、电压曲线或其他发动机的故障阈值套用到 DKVB。网页显示的“已记录”也不等于该项数值已经被判定正常。

## 快速入口：根据现有情况决定先做什么

| 当前情况 | 先做的工作 | 本文位置 |
|---|---|---|
| 静态压力没有记录，或单位不清楚 | 统一绝对压力单位，补齐同一时刻的环境、G31、G71 读数 | 第 2—4 节 |
| 发动机未启动，G31 明显偏离其他压力 | 先核对测量项，再检查 G31 插头、供电、接地及信号 | 第 4—6 节 |
| G71 偏离，G31 与环境压力接近 | 检查 GX9/G71 分支，不把 G31 当作唯一故障对象 | 第 4、8 节 |
| 摇动插头或线束时读数跳变、丢失 | 停止用这段压力记录判断增压能力，定位接触不良或线路故障 | 第 5—6 节 |
| 压力可信，驾驶请求保持，实际持续低于目标 | 保留压力证据，转入气路密封与增压调节检查 | 第 9—11 节 |
| 换挡、收油时实际压力与目标不一致 | 先重新选择可比工况，不能据此判定硬件故障 | 第 9—10 节 |
| 已确认插头、线路或传感器故障 | 修复明确故障点，再复测静态、扰动及负荷数据 | 第 6—8、12 节 |

## 1. 这个区域检查什么，不检查什么

### 1.1 三种压力来源不能混为一谈

| 对象 | 作用与位置 | 本区域怎样使用 |
|---|---|---|
| 环境绝对压力 | 车辆当前所处环境的压力参考；诊断仪中的具体来源需确认 | 发动机停机、压力平衡后，帮助核对静态读数 |
| G31 增压压力传感器 | 安装在增压空气管路上，反映该测量位置的压力 | 观察增压压力、检查传感器及连接线路 |
| G71 进气歧管压力传感器 | 位于进气歧管传感器 GX9 内；GX9 同时包含 G42 进气温度传感器 | 辅助静态一致性检查，观察节气门之后的压力 |

进气歧管压力用于发动机负荷、空气量等控制计算；温度与压力可以集成在同一传感器组件中。通用原理可参阅文末 HELLA 技术说明，但本文车型结构以本地 DKVB 手册为准。[W1]

**静态与动态的比较条件不同：**

- 点火开启、发动机未运转，并且各处压力已与环境平衡时，三个压力可以用于一致性核对。
- 发动机运行后，G31 所在增压管路与 G71 所在进气歧管之间受到节气门等因素影响，读数不同不自动代表传感器坏了。
- 比较“目标增压压力”时，应选择与其定义和测量位置相对应的实际压力，不能随意拿 G71 代替 G31。

### 1.2 本区域能形成的结论

可以形成以下判断：

1. 当前压力记录可信，或因缺失、单位、静态偏差、线路跳变等原因暂不可信。
2. 某个插头、端子、线束段或传感器存在经过复现和检查支持的异常。
3. 在指定工况下，实际压力跟随目标、持续偏低、间歇下降或过冲。
4. 下一步应继续修复测量链路，还是转向气路、增压调节等区域。

**仅凭 P0299、一个偏低读数或三个截屏，不能直接决定更换 G31、执行器或涡轮总成。** 反过来，静态压力一致也不能证明传感器在温度变化、振动或负荷下始终正常。

## 2. 开始前：把数据的含义统一

### 2.1 先保存故障发生时的信息

连接诊断仪后，先读取并保存发动机故障码、当前/偶发状态、冻结帧和用户描述，再决定是否清除故障码。记录故障发生在冷车、热车、加速、换挡还是松油阶段；记录近期是否动过插头、线束、增压软管或传感器。

特别注意：

- P0299 是增压不足方向的线索，不是传感器损坏的名称。
- 如果同时存在压力信号、电源或多个传感器相关故障，应先确认数据链路。
- 清码后暂时没有故障码，不等于故障已经排除；部分故障需要满足特定工况才会再次被识别。

### 2.2 统一绝对压力、相对压力和单位

本区域 PRS 压力字段按 **hPa、绝对压力** 记录。

| 换算项目 | 关系 |
|---|---|
| kPa → hPa | 1 kPa = 10 hPa |
| mbar → hPa | 1 mbar = 1 hPa |
| bar → hPa | 1 bar = 1000 hPa |
| 表压 → 绝对压力 | 绝对压力 = 表压 + 当地环境绝对压力 |

算例：当地环境压力为 980 hPa，仪表显示相对环境的增压为 0.8 bar，则对应绝对压力为 1780 hPa。不能把 0.8 bar 直接写成 800 hPa 绝对压力，并拿它与 1780 hPa 的目标绝对压力比较。

另一类常见问题是诊断仪显示 180 kPa，而手工录入 180 hPa。两者差了十倍，先改正记录单位，不要据此判断实际压力严重不足。

### 2.3 环境压力参考本身也要核对

不要把所有地区的环境压力都写成 1000 hPa，也不要把标准大气压当成车辆当前实测值。海拔、天气会改变实际环境压力。

天气应用中用于天气比较的海平面修正气压，不能未经换算就作为车辆所在地的实际压力。诊断仪显示的环境压力也可能是控制器计算、学习或存储的数值，不一定来自独立且已核实的传感器。出现争议时，应确认数据项定义，必要时使用适合的绝对压力参考仪表。

### 2.4 没有数据与传感器坏了是两回事

- 诊断仪不支持该测量项：记录“无法取得”，并说明工具或数据项限制。
- 数据项已打开但没有读数，且伴随明确的信号异常证据：记录“信号缺失”，继续查电路。
- 人员尚未采集：保持未记录，不填正常，也不填零。
- 读数长期固定：确认是否为替代值、旧数据或刷新中断，不能只因为数值接近环境压力就认为正常。

## 3. PRS-01—PRS-03：采集静态压力

### 3.1 操作顺序

1. 停稳车辆，确认发动机不运转；结束此前的加压或其他压力测试，使气路恢复到正常连接状态。
2. 开启点火，进入发动机控制单元的数据流。
3. 找到环境绝对压力、G31 对应压力、G71 对应进气歧管压力。保存测量项名称与单位，避免只记“压力 1、压力 2”。
4. 等待读数稳定、各处压力平衡后，尽量在同一时间记录三个数值。
5. 记录是否刚停机、是否存在数据刷新异常，以及参考压力的来源。
6. 对明显异常的读数重新读取一次，确认不是抄写、单位或通道选错。

不要求人为凑出三个完全相同的数字。传感器精度、显示分辨率和采样差异都可能带来一定偏差；应使用适用的厂家诊断判据。本地资料未提供可直接覆盖所有工况的 DKVB 静态压力差判废限值。

### 3.2 记录示例的正确形式

```text
状态：点火开启，发动机停机，读数稳定。
环境压力：填写实际数值、单位及参考来源。
G31：填写实际绝对压力；保留诊断仪数据项名称。
G71：填写实际绝对压力；保留诊断仪数据项名称。
异常备注：是否固定不变、偶发跳动、显示不支持或信号缺失。
```

## 4. PRS-04：静态不一致怎样定位

### 4.1 三者接近，且重复读取稳定

可认为静态检查暂未发现明显矛盾。下一步做插头外观及必要的线束扰动检查，再判断负荷记录。

不要省略用户明确提到的“偶尔跳变”。静态正常只能说明本次静态采集时没有复现，不会排除间歇故障。

### 4.2 G31 离群，G71 与可靠环境参考接近

按以下顺序缩小范围：

1. 确认 G31 通道和单位没有选错，发动机确实未运转。
2. 检查 G31 插头是否完全插入、锁止是否完整、针脚是否退出或受潮。
3. 监视 G31 压力并轻动插头及附近线束，观察能否复现读数变化。
4. 根据匹配的电路图检查供电、接地和信号线路，排除线路造成的偏差。
5. 核对传感器零件号与适用范围；检查安装孔、传感器外壳与密封圈状态。
6. 在接线、供电、参考压力均得到确认后，仍存在可重复偏差，才把传感器本体列为重点处理对象。

不能用“只有 G31 不一样”直接跳过线路检查，也不能把拔掉 G31 后出现的替代值视为修复成功。

### 4.3 G71 离群，G31 与可靠环境参考接近

检查进气歧管 GX9 组件及其连接器。GX9 内包含 G71 与 G42，应同时观察相关温度数据是否也存在明显异常，作为共同连接故障的线索，而不是据此直接认定两路都坏了。

确认压力没有残留、数据项没有选错后，按与 G31 相同的“外观—扰动—电路—本体”顺序检查。拆装方法见第 8 节。

### 4.4 两路都偏离，或三个数互相矛盾

先检查共通条件：单位、绝对/相对压力、参考气压、读取时机及诊断仪刷新。随后检查故障码和供电情况。

两个读数一起跳变可能与共同电源、接地、控制器或采集通信有关，但是否共用同一支路必须由电路图确认，不能仅凭“同时异常”就认定共用 5 V 电源故障。若只有诊断仪曲线同时停顿，应先排除记录链路问题。

## 5. PRS-05—PRS-06：插头、端子与线束检查

### 5.1 外观检查不是只看插头在不在

熄火并按车辆电气操作要求关闭电源后，检查 G31 连接器和邻近线束：

1. 插头有没有插到底，锁扣是否断裂，轻拉插头壳体是否松脱。
2. 线束是否被夹在支架、护板边缘，是否靠近高温部件，是否有拉得过紧的区段。
3. 拔开插头后，观察针脚弯曲、端子后退、氧化、潮气和密封件缺失。
4. 查看线束进入插头的位置是否折伤、硬化，绝缘外皮下是否有腐蚀痕迹。
5. 查看传感器壳体和插座是否开裂，确认问题不只是外部插头壳损坏。

检查端子夹持力应使用匹配工具，不要把普通表笔强行塞进端子孔；这种做法可能撑大端子，制造新的间歇故障。

本地电路图中的 G31 连接器为 T4ct，GX9/G71/G42 连接器为 T4b。两者都是四针连接器，但不能由针数推出每一针的用途。[L4]

### 5.2 摇动线束时怎样判断信号变化

优先在点火开启、发动机停止的静态条件下做轻微扰动，避免把真实负荷变化误认为电气跳变。

1. 打开 G31 压力实时曲线，先确认不触碰时读数是否稳定。
2. 分别轻动插头壳体、插头尾部、固定夹附近及存在磨损的线束段，一次只改变一个位置。
3. 记录异常出现的准确时刻和触碰位置；松手后观察是否恢复。
4. 重复一次相同动作，确认变化能否稳定复现。
5. 若条件允许，同时记录对应电路的供电、接地或信号，分清是测量线路变化，还是诊断仪刷新中断。

| 选项 | 实际含义 | 接下来的动作 |
|---|---|---|
| 信号稳定 | 本次扰动没有复现异常 | 保留结果；对仅热车出现的问题按其发生条件复查 |
| 间歇出现 | 指定位置扰动时读数跳变，随后恢复 | 优先检查该处端子夹持、退针或线芯断续 |
| 信号丢失 | 数据或有效信号消失 | 先核对供电、接地、线路与采集状态，不直接换传感器 |
| 无法检查/无法取得 | 当前无法完成这项测试 | 写明缺少工具、无法接近或故障条件无法复现 |

不要大力拉拽整束线缆，也不要在发动机运行时把手、表线放到皮带、风扇或高温件附近。只有在确有必要复现运行条件时，才安排相应防护和固定测量线。

## 6. 电路故障的具体处理

### 6.1 先确定电路类型，再决定怎么测

压力传感器并非都采用相同信号方式。产品层面既存在模拟电压输出，也存在数字 SENT 等方式。[W2] 因此，“压力传感器通常是 5 V”“四针就一定某针是信号”都不能代替实车电路确认。

本地资料可以定位连接器与控制器线路，但本文没有列出未经确认的针脚电压和传输曲线。实际测量按以下顺序进行：

1. 核对车型、发动机、传感器零件号与对应电路图。
2. 确认供电、接地、信号端子，以及信号是模拟还是数字。
3. 使用高阻抗仪表及合适转接线检查供电；对带载状态和接地点电压降进行核对，而不只测空载是否“有电”。
4. 模拟信号按该型号的压力—输出关系检查；数字信号使用相应波形或诊断方法，不用万用表的平均电压判定压力精度。
5. 做电阻、连续性或短路检查前，按维修要求断电并隔离相关控制器/部件，避免带电测电阻。

不要用试灯加载传感器参考电源，不向信号端子送入蓄电池电压，不使用绝缘摇表直接测量仍连接控制器的线路。

### 6.2 插头松动或锁扣损坏

若只是未插到位，检查端子及密封无损后重新插入并确认锁止，再做轻拉和扰动复测。若锁扣或壳体损坏，更换匹配的连接器外壳或维修线束，不能用扎带临时捆紧后就结束维修。

重新连接后要确认：端子没有后退、密封没有翻折、线束有活动余量，且与原来的高温或摩擦点保持合适距离。

### 6.3 针脚损伤、端子夹持不良或腐蚀

弯曲、严重氧化、镀层损伤或夹持力不足的端子，应按适用维修方案更换，不以反复掰直、刮亮作为最终修复。若传感器插座本体损伤，评估更换传感器组件。

发现潮气时同时处理进入路径：插头密封缺失、壳体裂纹或不正确的清洗方式。不解决进水原因，单纯吹干可能只会短期恢复。

### 6.4 线束磨损、断续或短路

定位到明确损伤段后，使用匹配线径、耐温等级和端子的维修线，按车辆线束修复工艺完成连接、密封及固定。不能把导线拧在一起包胶带作为最终维修。

处理后沿原路径恢复固定，消除拉力、锐边和高温影响。复测不仅要看通断，还要在相应工作状态下确认供电、接地和信号稳定；蜂鸣器导通不能证明线路在振动或负载下可靠。

### 6.5 什么情况下才考虑传感器本体

当以下证据能够同时成立时，传感器本体才成为较明确的维修对象：

- 数据项、单位、参考压力和工况均正确；
- 插头、供电、接地及信号线路检查未发现能解释异常的问题；
- 传感器偏差、丢失或不合理变化可以重复复现；
- 零件适配无误，且没有外部安装或测压通道问题。

不要仅凭换一个零件后暂时正常就反推旧件必坏。拆插动作本身可能临时恢复接触，应保留更换前的故障证据。

### 6.6 从“检查电路”展开到可执行测量

准备高输入阻抗万用表、不会撑开端子的转接线、匹配电路图和能显示实时压力的诊断仪。短暂跳变或数字信号需要合适示波器。先在电路图上找到部件侧与控制器侧，再读取实物壳体上的腔位编号；观察插座正面与线束背面时左右会相反，不按线色单独确定针脚。

本地图能识别 G31 的 T4ct、GX9 的 T4b 及相连 J623 回路；这些标识用于找图和找插头，不表示已确认各针的信号制式或额定值。测量前将实际供电端、传感器回路地及信号端标注在工作记录中。不能把四针结构自动解释成“电源、地、两个通用模拟信号”。

**第一步：先检查电源与回路地，保留工作负载。**

1. 在关闭电源时连接适配转接线，避免刺穿绝缘或损伤防水密封；恢复连接后，按允许条件开启点火。
2. 将电压表跨接在已确认的供电端与传感器回路地，记录稳定状态和故障出现时的电压。这里只测量，不外加电源。
3. 供电异常时，沿该供电支路比较上游与部件端。对同一段导线或同一接点跨接测电压差，并保持相同工作状态，定位电压损失发生的位置。
4. 对传感器回路线，比较部件侧回路地与图示对应控制器回路地；需要时再核对控制器主接地。传感器回路地不一定等同于任意车身搭铁，不能用跨接到车身的方法代替诊断。
5. 如果故障只在轻动插头时出现，保持测量连接，分别扰动壳体、尾部和可疑线束段；将压力变化与电源/回路地变化的时间对齐。

带负载测电压差能帮助发现空载测电阻不易暴露的连接问题；这是 [Fluke 汽车电压降诊断](https://www.fluke.com/en-us/learn/blog/automotive/electrical-automotive-troubleshooting)的核心方法。此处不将起动机等大电流回路的容许压降直接用于传感器回路。

**第二步：区分信号变化来自传感器、线路还是采集。**

| 同时观察到什么 | 更有价值的下一项检查 | 暂时不能得出的结论 |
|---|---|---|
| 压力跳变时供电或回路地也变化 | 沿变化的支路定位接点、供电或共用连接；核对图示是否确实共用 | 直接判 G31 本体坏 |
| 供电稳定，部件端信号正常而控制器端不同 | 断电隔离后查中间连接、断续和串线，再恢复工作状态复核 | 只更换传感器 |
| 两端信号变化一致，但诊断数据解释不符 | 核对数据项、单位、信号类型、工具刷新与控制器解释 | 直接认为是管路真实压力变化 |
| 信号和供电均稳定，只是诊断曲线同时停顿 | 减少采集项目，核查接口与日志时间，重建连续采集 | 认定多个部件同时失效 |
| 电源与线路已可靠验证，传感器偏差重复存在 | 核对零件适配、测压孔与对照压力，再评估本体 | 因一次换件后正常反推旧件必坏 |

**第三步：只对已确认类型的信号使用对应工具。** 模拟型记录信号与独立压力变化的对应关系；没有该型号标定曲线时，只能判断中断、突变和重复性，不能换算成精确压力误差。数字型使用对应协议和波形检查，不能拿万用表平均电压判断压力是否合格。[Pico 的 SENT 检查说明](https://www.picoauto.com/library/automotive-guided-tests/communication/sent/AGT-404-sent-fast-extended-testing/)展示了数字数据包与解码方法，但不证明本车当前传感器一定采用 SENT。

连接示波器前核对通道是否共地及允许输入范围；不能将共地夹跨接两个不同电位。电阻、连续性和对地短路测量放在断电、确认无电并按图隔离相关电子单元之后，不能在仍连接控制器的回路上用绝缘摇表测试。

### 6.7 没有精确阈值时仍能做什么

可以可靠完成的事项包括：核对输入单位与数据通道、确认插头锁止和明显损伤、定位哪一段扰动会重复触发异常、比较同一信号在线路两端的差异，以及确认修后相同条件下异常是否消失。不能据此给出传感器全量程精度合格结论。

需要精确判定时，补齐的是具体项目：部件号对应的信号定义、各端子功能、规定工况的电气值或压力误差范围。记录中写“等待本部件信号标准”，比写“检查不了”更便于下一位师傅接续。

### 6.8 修完插头或线束后怎样确认没有只恢复一时

恢复原位置固定和密封后，先在与处理前相同的静态条件采集基线；按相同顺序轻动原故障部位，比较是否还能复现。对热态故障另安排相近温度复查，不能用冷态正常替代。静态和扰动可信后才进入第 9 节的负荷记录；压力恢复可信与发动机增压恢复是两个分别保存的结果。

## 7. G31 的拆卸、安装与处理后核对

### 7.1 适用结构与紧固值

本地《增压空气系统》装配图将 G31 列为部件 15，其固定螺栓为部件 14，紧固力矩 **5 Nm**；对应 O 形环需更换。[L1]

注意两个容易混淆的值：手册中 V.A.G 1783 工具的 2—10 Nm 是工具量程，不是 G31 的紧固值；软管卡箍的紧固要求也不能拿来拧传感器螺栓。

![G31 安装位置与拆装步骤](assets/manual-pages/04-G31增压压力传感器位置.png)

### 7.2 操作顺序

1. 关闭点火，确认部件温度及作业条件适合操作。需要从下方作业时，按规定可靠举升车辆。
2. 按本地手册拆下下部隔音垫/护板，露出 G31 所在空气管路。
3. 清理传感器外部附近的松散污物，避免拆出后进入安装孔。
4. 解锁并拔下图中连接器 2，检查其端子和密封状态。
5. 拧出固定螺栓 1，沿安装方向小心从空气管中取出 G31。
6. 检查传感器外壳、密封槽和安装座。安装座开裂、密封面损坏时，不能只换传感器后继续使用。
7. 使用适配传感器及新 O 形环，保持安装面清洁；按对应零件的装配要求放置密封圈，避免切伤或挤出。
8. 使传感器平正入位，将对应固定螺栓按 **5 Nm** 紧固，重新插入并锁止连接器。
9. 整理线束，恢复拆下的护板/隔音垫。
10. 开启点火复查静态压力，再做插头扰动与后续工况验证。

不要将溶剂灌入感压孔，不用尖物探通敏感元件，也不要用高压气体直接冲击感压部位。污染或损坏应按部件要求处理，而不是把任何压力异常都归为“洗一下就好”。

### 7.3 传感器密封漏气与电气故障要分开

G31 数据可能正常，但安装处 O 形环泄漏；也可能安装处不漏气，但传感器电气输出异常。前者需要修复密封及安装座并核对泄漏，后者需要解决测量链路，不能相互替代。

更换后是否需要基本设置或其他操作，按该零件和诊断工具的适用程序确定；本文不设定所有压力传感器更换都必须做某个通用学习程序。

## 9. PRS-07—PRS-10：采集可比较的负荷压力

### 9.1 什么时候可以开始

如果当前信号已经丢失、明显跳变或单位仍不清楚，应先解决这些问题。不是必须把其他区域全部填完才允许观察压力，而是不能用已知不可靠的数据证明增压能力。

确认车辆适合进行相应工况测试。存在明显机械异响、严重泄漏、失火、过热或其他不适合负荷测试的情况时，先处理这些限制。

### 9.2 怎样选数据项

最小记录集合应能同时表达“要求多少、实际多少、当时在做什么”：

- 对应测量位置的目标绝对压力、实际绝对压力；
- 发动机转速、负荷、驾驶请求；
- 时间戳、挡位或采集工况。

必要时增加节气门状态和与扭矩限制有关的数据，但不要无目的地勾选大量数据项。Ross-Tech 文档指出，采集项目增加可能降低采样速度，从而漏掉短暂跳变；UDS 控制器应使用适用的高级测量值，而不是照搬旧式固定组号。[W3]

### 9.3 采集步骤

1. 建立记录文件，先保存稳定状态的基线，确认数据持续刷新。
2. 在适合且安全的条件下复现用户描述的负荷区间；道路测试由驾驶员驾驶、另一人负责记录，不能边开车边操作电脑。[W4]
3. 保存包含压力建立、持续负荷及异常发生前后的一段连续记录，而不是只截取异常瞬间。
4. 标出换挡、松油、驾驶请求变化及故障感受出现的时刻。
5. 从同一次记录中选择三个有代表性的时间点，填入 PRS-08、09、10。三个点应能看出趋势，不应从不同条件拼出一条“曲线”。
6. 保存原始记录文件，便于核对三帧之间是否发生过瞬态变化。

三帧是页面的摘要，不是完整动态记录的替代品。若需要判断很短的掉压或电气跳变，应回看连续曲线，必要时使用更适合的采集方式。

### 9.4 每帧怎样填写

| 字段 | 填写要求 |
|---|---|
| 转速 | 同一时间点的发动机转速，单位 rpm |
| 负荷 | 诊断仪相应负荷数据及百分比；保留数据项定义 |
| 驾驶请求 | 记录保持、降低等实际状态；不要仅写“正常” |
| 目标压力 | 对应目标绝对压力，统一为 hPa |
| 实际压力 | 同位置定义的实际绝对压力，统一为 hPa |
| 采集时间 | 实际时间或本次日志中的相对时间 |
| 挡位/工况 | 说明挡位、加速阶段及是否处于换挡或收油过程 |

### 9.5 PRS-07 不可比较时怎样处理

- **转速变化过大：** 重新选择更接近的转速窗口，或者明确把数据作为压力建立过程，而不是稳定负荷结果。
- **负荷变化过大：** 重新选取相似负荷段，不能只凭转速接近就认为可比。
- **驾驶请求中断：** 单独标出中断时刻，压力回落不作为持续增压不足的证据。
- **无法取得：** 保留原因，例如场地不允许、安全条件不足或工具不能同步采集。可以先处理已有明确的插头/线路问题，不必编造三帧。

## 10. PRS-11—PRS-12：怎样解释趋势

### 10.1 持续跟随目标

在本次可比工况中，实际压力随目标变化，没有观察到明显持续偏离，可以说明本次记录没有复现相应增压异常。

如果用户只在热车或特定挡位出现故障，结论应保留条件：“本次工况未复现”，而不是宣布所有工况正常。也不能因此抹去此前已经保存的异常记录。

### 10.2 连续增压不足

如果静态与扰动检查支持信号可信，采集工况可比，目标保持而实际持续偏低，应优先把它理解为需要进一步定位的增压不足表现。

下一步先结合已知线索：

- 有接头松脱、漏气声或明确泄漏响应：优先检查对应气路连接与密封。
- 气路检查未发现解释性问题，但调节执行器、连杆或控制响应异常：转向增压调节机构。
- 伴随其他动力系统故障或控制器限制：先确认目标和扭矩控制状态，避免把主动降扭误当涡轮输出不足。

P0236 等可信度故障也可能涉及管路、接线、传感器或控制相关原因，不等同于单一零件坏了。[W5]

### 10.3 间歇掉压

先区分两类形态：

1. **突然跳到不合理数值、伴随信号丢失或可以被线束扰动复现：** 优先返回电气检查。
2. **数值连续但短时下降，且与换挡、请求降低、节气门变化或调节动作对应：** 先解释控制工况，再判断是否存在机械问题。

只有驾驶踏板保持，不代表发动机控制器始终要求相同增压。变速器换挡、牵引控制、温度保护等都可能影响扭矩与压力目标；应看记录中的目标变化，而不是仅依据脚有没有松开。

### 10.4 压力过冲

先排除单位、信号跳变和采样错位。若数据可信且实际持续高于目标，保留异常发生时的工况，转向增压调节响应检查。明显过冲或伴随异常运转时，不反复增加负荷来“验证得更清楚”。

不能因为页面当前围绕 P0299，就把所有压力偏差都写成增压不足；过冲需要单独解释。

### 10.5 数据不可信

明确写出不可信的原因和恢复方法：例如 G31 间歇丢失、目标与实际单位不同、三个点来自不同挡位，或缺少驾驶请求记录。不要把它改写成“尚未发现故障”。

### 10.6 数值算例：用差值说明现象，不把算例当标准

三个可比时间点的目标/实际绝对压力分别为：1900/1580、1950/1620、2000/1670 hPa，则对应差值为 320、330、330 hPa。这说明三个记录点都存在实际低于目标的现象。

但是否足以判定故障，仍要结合持续时间、压力建立阶段、工况及适用诊断标准。本文不把 320 hPa 或任一固定差值定义为 DKVB 厂家判废标准，也不把静态差值与动态差值使用同一限值。

## 11. 常见情况组合与针对性处理

### 情况 A：G31 静态偏高，其他参考接近，线束扰动无变化

先确认绝对压力单位和正确通道；检查传感器型号及安装情况，再做供电、接地、信号检查。若线路与参考均可靠且偏差重复存在，处理传感器本体。完成后复测静态一致性与负荷跟随，而不是只清码。

### 情况 B：G31 插头松动，轻动插头时压力间歇跳变

优先处理插头锁止与端子接触。端子、密封完好且只是未插到位时重新锁止；壳体、端子损伤时更换对应维修件。修后在同一位置做相同扰动，并观察连续曲线；未完成这一步前，不依赖旧压力曲线决定气路维修。

### 情况 C：存在潮气，冷车正常、热车或振动时信号丢失

保留异常条件，检查连接器密封与腐蚀，同时核查供电/接地是否随故障变化。解决潮气来源和损伤端子，不只把插头吹干。复测应覆盖原来的温度或振动条件；没有复现条件时，写明已完成的检查和仍待观察部分。

### 情况 D：G71 信号缺失，G31 有读数

先确认诊断仪支持该数据项，随后检查 GX9 插头及对应电路；同时查看 G42 是否有相关异常。不要为凑齐三路静态压力而把 G71 填成环境压力。确认为 GX9 本体问题时按第 8 节处理，修后核对压力与温度两路数据。

### 情况 E：静态可信、信号稳定，负荷下实际持续偏低

此时没有充分理由继续盲目更换压力传感器。检查近期作业处、增压软管座合与外部密封线索，必要时对气路进行适用的定位检漏。气路没有解释性发现时，再结合调节机构的记录决定下一分支，不直接跳到涡轮总成。

### 情况 F：三帧记录跨越换挡，驾驶请求降低

原记录保留但标明不可作为稳定负荷对照。重新选择请求保持且工况可比的记录段。此时先改进采集，不安排传感器或涡轮更换。

### 情况 G：静态正常，摇动线束稳定，实际压力偶尔出现单点突变

检查原始日志的时间间隔、采样中断及同一时刻其他通道是否停顿。若异常真实且可重复，进一步捕获电气信号；如果只是记录链路异常，先改善采集。单张截屏不足以在电路与气路故障之间作选择。

### 情况 H：更换 G31 后压力仍低

先确认替换件型号、密封、插头和静态结果。如果测量可信度已恢复，但同工况实际仍低于目标，应继续气路/调节诊断，而不是再次更换同一传感器。记录“测量问题已处理”和“增压问题仍存在”两个不同结果。

### 情况 I：实际压力能跟随目标，但用户仍感觉动力不足

保留“本次压力跟随未见明显异常”的条件结论，结合请求、负荷、失火、燃油与排气等记录继续其他动力方向。不要求本区域一定给出一个压力系统故障，也不把没有压力异常等同于车辆没有问题。

### 情况 J：工具不支持三帧，但插头有明确损伤

可以先处理已有明确证据的连接器问题，并完成能做的静态与扰动复测。动态效果留待具备采集条件后验证；无需把尚未取得的动态数据填写为正常。

## 12. 修复后怎样确认结果

### 12.1 测量链路修复后的顺序

1. 检查插头锁止、线束固定、传感器安装与密封。
2. 保存修后点火开启/发动机停机时的环境、G31、G71 读数。
3. 重做原先能引出故障的轻微扰动，确认读数是否仍跳变或丢失。
4. 保存修前故障记录后，按适用流程清除故障并重新读取，区分“清除成功”与“在原条件下未再发生”。
5. 在条件允许时，用相近挡位、转速、负荷与请求重复原工况，比较目标/实际压力曲线。
6. 记录动力症状是否改善，是否仍存在增压不足、过冲或其他故障。

### 12.2 应记录哪些实际处理

记录具体对象和动作，例如“更换 G31 插头壳及受损端子”“修复靠近固定夹的两处线束损伤”“更换 G31 与 O 形环”。不要只写“检查处理完成”。

保留修前/修后状态、零件信息、修复位置及复测条件。建议中的“准备更换”不是已经更换；没有实际执行的复测不能写成通过。

### 12.3 什么时候可以结束这个区域

- 测量链路可靠，原异常条件下未再出现信号问题；若动力问题仍存在，携带可信压力数据转向其他区域。
- 已修复明确测量故障，并在原条件下确认压力表现与主诉改善，可记录本区域处理结果。
- 无法复现或缺少必要测量条件，说明限制和后续观察办法，不把“暂时没报码”当作完整验证。

结束本区域不要求其他所有区域必须填满；但若症状仍在，就不能把本区域检查完成写成整车故障已排除。

## 13. 与其他排查区域怎样配合

| 本区域结果 | 带给其他区域的证据 | 下一步的实际重点 |
|---|---|---|
| 信号可靠、实际持续低于目标，且有漏气线索 | 原始压力日志、请求与工况、漏气位置线索 | 气路接头座合、密封及定位检漏 |
| 信号可靠、气路没有解释性发现，调节响应异常 | 目标/实际趋势及调节异常出现时刻 | 执行器、连杆、控制响应与适用设置 |
| G31 跳变可以被插头扰动复现 | 触碰位置、跳变时刻及电气测量 | 优先解决测量链路，不以跳变推断涡轮故障 |
| 目标本身下降，伴随其他系统限制 | 请求、目标、故障码与限制发生条件 | 其他动力系统方向及控制器主动降扭原因 |
| G71 与 G31 运行时不同，静态均合理 | 两者位置和相同时间的节气门/工况 | 先解释测量位置，不用运行差值直接判传感器坏 |

气路手册中的 **0.5 bar** 是相应静态检漏装置的压力限制，不是发动机行驶时目标增压的上限，也不能拿来判断本区域的绝对压力读数是否超标。[L1]

## 15. 如何把这份资料与当前区域一起用于分析

### 15.1 输入应包含什么

选择“增压压力测量”区域时，将以下内容一起提供：

1. 车辆品牌、车型、年款、发动机、故障码与用户主诉。
2. PRS-01—PRS-12 当前有效记录，包括数值、单位、无法完成原因；未检查的明确保留为未知。
3. 本文与当前车辆适配的正文，及资料版本、章节编号。
4. 其他区域已经保存且会影响本次判断的少量事实，例如明确漏点或调节异常；不把其他区域未检查误写成正常。

区域与资料的对应应使用稳定的区域标识和资料版本，不依赖模型猜文档名称。对于第一版，直接把本区域绑定到这一份参考即可，不必先把全部情况组合做成资料库。

### 15.2 分析结果应该回答的四个问题

**第一，当前压力数据能不能信？** 说出理由，例如静态一致、扰动稳定，或者 G31 在插头扰动时丢失。

**第二，现有结果最支持什么方向？** 解释依据与未知部分，区分测量链路问题、真实压力异常和不具备比较条件。

**第三，现在先做哪一步？** 优先给一个明确动作，例如检查并修复松动端子，而不是同时列出更换传感器、检漏和更换涡轮。

**第四，做完后怎么决定继续还是转区？** 写出要记录的结果与条件分支，例如修后信号稳定但压力仍低，则转气路检查。

当数据已经足以确定下一步时，不必把所有未记录问题再次罗列为前置要求。对缺少的关键数据，只说明它影响哪个判断、怎样取得；对不影响当前动作的缺项，不让其淹没主要建议。

### 15.3 分析引用资料的方式

正文直接写出动作、对象和判断方法，例如“检查 G31 连接器锁止与端子后退情况；如果扰动该位置可复现跳变，先修复连接器，再做相同扰动复测”。来源作为补充依据显示，而不是只输出“参见第 5 节”。

图片用于确认部件位置与装配关系；如果分析过程没有实际读取图片，就只依据配套文字，不声称已从图片确认实车状态。
