# 探岳 DKVB 涡轮增压器本体检查与维修参考｜详细版


> 本次修订：2026-09-26，补充操作方法、结果分支与修后确认；新增内容为本地资料和公开技术资料的综合整理，不将其他车型参数作为本车标准。
> 版本：TURBO-REFERENCE-1.1｜整理日期：2026-09-26  
> 适用范围：2019 年探岳专题中 DKVB 发动机的涡轮增压器本体区域，对应 TUR-01～TUR-10。  
> 主要内容：壳体与固定、入口与叶轮、机油和冷却液连接、排气与增压连接、机械线索、异响烟雾、维修分流及处理后验证。

本资料按“看到了什么 → 怎样确认 → 处理哪个对象 → 怎样复检”组织。外部连接问题、本体损伤和发动机其他问题分别判断；已经明确的异常可以先处理，不要求把所有区域检查完才提出有针对性的建议。

车型结构和部分装配要求依据本地手册图核对；检查顺序、情况组合与记录方法为综合整理。涉及总成型号、内部间隙、润滑压力、拆装前置步骤及设置程序时，应与具体车辆和零件版本匹配。没有取得的观察保留未知，不能从资料内容反推车辆已经存在某种故障。

## 阅读入口：根据当前情况选择检查路线

| 当前发现 | 优先阅读 | 本轮要解决的问题 |
|---|---|---|
| 壳体疑似裂纹、固定松动或碰伤 | 第 3 节 | 损伤是否在本体，还是隔热板、支架或连接处 |
| 入口可见异物、叶片缺口或异常积油 | 第 4 节 | 是否需要停止运行，污染从哪里来、到哪里去 |

| 冷却液结晶、湿痕或液位下降 | 第 6 节 | 定位接头、管路或本体，确认是否仍在泄漏 |
| 排气积炭、增压侧漏气或连接松动 | 第 7 节 | 区分涡轮前、涡轮后及压力侧连接 |
| 卡滞、间隙或叶轮擦碰线索 | 第 8 节 | 将手感线索转为可检查、可测量的对象 |
| 啸叫、刮擦声或负荷相关异响 | 第 9 节 | 区分气流声、连接泄漏、附件振动和内部接触 |
| 蓝烟、黑烟或类型不明的烟雾 | 第 10 节 | 先辨别烟雾来源，再关联机油、冷却液和燃烧状态 |

## 1. 本体区域检查什么

### 1.1 本体、外围连接和控制机构的区别

| 对象 | 本区域关注内容 | 与其他区域的关系 |
|---|---|---|
| 压气机壳与压气机叶轮 | 壳体损伤、入口异物、叶片异常和擦碰线索 | 上游空滤和导管问题可能带来异物；下游漏气应由气路区域定位 |
| 涡轮壳与排气侧 | 壳体、连接、热损伤、泄漏和可取得的机械证据 | 排气受阻、燃烧异常可能影响其工作和寿命 |
| 中间壳体与轴承系统 | 润滑、油液异常、轴系卡滞或间隙线索 | 供回油及曲轴箱通风问题不能忽略 |
| 机油与冷却液连接 | 管路、接合处、密封及固定 | 外部泄漏并不自动证明内部损坏 |
| 隔热板、支撑与紧固件 | 松动、碰撞、干涉、振动 | 可能制造听起来像本体故障的声音 |
| V465、连杆和废气旁通机构 | 与本体异常的关联及机械连接线索 | 电路、输出测试和基本设置见调节机构资料 |
| N249 与增压连接 | 局部漏气、安装及功能关联 | 专项内容分别见调节机构和空气通路资料 |

“涡轮增压器本体”不是只看一个外壳，也不等于把附近所有故障都归到总成更换。应明确异常所在部位以及它与主诉的关联。

### 1.2 P0299、异响和烟雾都不是单独的换件结论

低增压可以来自气路、控制、测量或发动机输出条件。蓝烟和油耗需要区分机油进入路径；异响需要定位来源。BorgWarner 的诊断资料将这些症状分别对应到多类原因，并提醒先查明基础故障，避免只更换涡轮。[来源：BorgWarner 故障排查](https://www.borgwarner.com/aftermarket/boosting-technologies/troubleshooting)

本资料采用的判断顺序是：**直接观察优先于猜测；明确损伤优先处理；运行效果另行验证。** 可见叶片断损无需等更多选项才停止运行；只有轻微油膜，也不能因为另外选了“动力不足”就升级为本体失效。

## 2. 检查前的准备与分流

### 2.1 继承已有信息，补充真正会改变判断的内容

- 主诉出现于冷车、热车、加速、松油、怠速还是持续负荷；声音或烟雾是否与同一工况相伴。
- 近期有无更换机油、拆装空滤/气管、处理排气、维修执行器或更换涡轮。
- 机油和冷却液是否实际减少，补充量、里程及观察时间是否可追溯。
- 故障码、冻结帧、目标与实际压力是否已保存，压力信号是否可信。
- 已知气路漏点、控制机构异常或失火等事实，是否能解释部分症状。
- 本轮可见范围、已拆开的部位及无法检查原因。

接诊和其他区域已有记录直接使用。没有量过油耗就不能写“油耗正常”；没有接近叶轮就不能写“转动顺畅”。

### 2.2 先看原貌，再清理

先拍摄或文字记录湿痕起点、积炭边缘、碰撞位置和固定状态，再进行局部清理。照片应包含一个可识别的相邻部件，避免只有油污特写却无法定位。

外表清理的目的，是让新产生的痕迹容易辨别。清洗液不得灌入进气、油路、电气接口或高温部位；不能用清洗后的干净外观代替泄漏复核。

### 2.3 可继续检查与应停止运行的情况

停机、冷却并防止意外启动后，才接近旋转部件和高温连接。需要举升时保证支撑可靠；运行观察应在恢复封闭连接后进行，人员和设备避开运动件。

出现叶片缺损、明显擦碰或卡死、大量积油、明显漏油到高温排气部位、持续浓烟、润滑报警或冷却异常时，停止启动或负荷测试，先处理原因和后果。Garrett 的诊断指南同样要求在异常烟雾及明显机油消耗等情况下中止试验。[来源：Garrett 系统诊断指南](https://www.garrettmotion.com/turbo-replacement/turbo-diagnosis/go-to-diagnostics/)

只有“不容易接近”时，可以继续完成其他可见检查，并把受限项目记录为未知；无需为填满问题而冒险拆解。

## 3. TUR-01：壳体、固定位置、裂纹与碰撞

### 3.1 检查路径

1. 在未清理前看壳体、隔热板、支架与相邻管路的相对位置。
2. 找积炭集中边缘、局部油湿、裂纹状线条、紧固缺失和碰撞变形。
3. 将疑似裂纹与铸造纹理、接缝和表面污染区分；光线或照片不能确认时保留“裂纹线索”。
4. 停机冷却后检查外部支撑是否松动，分清隔热板活动还是总成固定异常。
5. 检查松动部位是否已经拉扯供回油管、冷却管、排气或增压接口。

### 3.2 对应选项怎样处理

| 当前选择 | 补充检查 | 处理方向 |
|---|---|---|
| 正常/未见异常 | 写明看到了哪些面和固定点 | 保留外观结果，不扩大为内部正常 |
| 裂纹线索 | 标注部位、长度方向、是否伴随泄漏痕迹；必要时专业确认 | 确认受损承压或高温壳体后制定总成/部件处理方案 |
| 松动 | 区分隔热板、支架、法兰紧固或总成位移 | 检查紧固件、螺纹与配合面后恢复，损坏件更换 |
| 碰撞痕迹 | 查看变形是否影响接口、管路、壳体和机构活动 | 同时消除干涉及安装应力，不能只修饰表面 |
| 无法检查/无法取得 | 遮挡位置、温度、举升或工具条件 | 完成其他可取得观察，必要时安排有条件检查 |

### 3.3 外部固定问题的维修组织

先确认松动原因。紧固件缺失或失效时，应匹配原结构；螺纹损坏不能用更大力矩补偿。隔热板变形时，恢复其固定和间隔，不能把拆掉隔热板当作异响修复。

总成、排气和管路应自然对位。若必须用螺栓强拉才能接合，应先查支撑及安装位置。恢复后复查接口密封和热态相关症状；仅消除松动不代表低增压已经解决。

## 4. TUR-02：入口异物、异常油液和可见叶轮损伤

### 4.1 安全观察入口

在停机冷却、确认不会意外启动后，按适用流程解除需要观察的入口连接。先清理管口外部，保护拆开的导管，清点工具与紧固件。用照明或合适观察设备查看可见区域，不将手、棉布或硬物伸入叶轮间隙。

记录叶片边缘、可见壳体内壁及入口导管。一个角度看不到全部叶片，就写清视野限制。不得用压缩空气吹动叶轮来判断转速或声音。

### 4.2 可见异物

先停止启动，判断异物是在入口前被拦住，还是已经接触叶轮。保留异物位置和形态，追查空滤密封、导管破裂、近期拆装遗留及上游部件缺损。

对于已经进入叶轮区域或可能产生碎片的情况，不能只拿出看见的一块就结束。需要检查压气机叶片、壳体和下游气管/中冷器的污染范围；必要时评估发动机吸入风险。被动损伤发生后，处理来源和残留物与处理总成本身同样必要。

Garrett 将异物、润滑不足及机油污染列为常见损伤机制；这里采用原因追溯的思路，不将其统计比例作为本车诊断概率。[来源：Why do turbochargers fail?](https://www.garrettmotion.com/fr/news/newsroom/article/why-do-turbochargers-fail/)

### 4.3 可见损伤

叶片缺口、卷边、变形及壳体擦碰痕需要专业核查。不要现场打磨叶片、掰正叶尖或松动轴端螺母“修复平衡”。可见损伤支持进入本体专项处理，但失效根因可能仍在上游气路或润滑系统。

记录应包含损伤对象、位置、可见范围、是否发现碎屑及伴随症状。仅有照片反光或积污无法确认缺口时，保留待确认，不能直接生成“叶轮断裂”的维修事实。

### 4.4 异常油液

先描述是薄膜、局部湿润、液滴还是可见积液，并说明位置在压气机入口、出口还是下游。入口已有油液与出口新增油液不是同一观察；曲轴箱通风带入、回油条件和发动机本身均可能影响判断。

| 发现 | 下一步 | 不宜直接得出的结论 |
|---|---|---|
| 少量薄膜，没有已知油量变化 | 核对来源，结合通风系统、历史拆装和后续变化 | 涡轮漏油或全部正常 |
| 清理后短期又明显积聚 | 对照油位/里程，查通风与供回油，必要时专项检测 | 只换一个通用“油封”即可 |
| 大量积液或油液伴碎屑 | 停止运行，检查下游和损伤来源 | 排掉积油后可直接路试 |
| 异常油液伴蓝烟、擦碰或叶片损伤 | 优先评估本体及润滑系统，同时核实发动机侧原因 | 多个选项一勾选就自动批准换总成 |

本资料不设“允许积油多少毫升”的统一阈值。不同位置、时间和运行条件下的液体不能简单比较。

## 5. TUR-03：供油、回油连接与润滑原因

### 5.1 外部干燥不等于供油正常

“干燥”只说明本次可见外部没有明显湿漏。供油内部受限、油压异常或回油受阻仍可能需要其他证据确认；不能用这一选项排除整个润滑系统。

### 5.2 渗漏与明显泄漏怎样定位

1. 看湿痕最高处，区分上方流下、供油接合处、回油接合处和管壁。
2. 记录是否持续形成液滴，是否接近高温排气，机油液位和报警情况如何。
3. 局部清理后，在适于运行且连接恢复完整的条件下复查；严重泄漏先维修，不为定位强行运行。
4. 拆开前保留原始记录，按油路维修要求防止脏物进入。
5. 检查密封件、沟槽、法兰及管路是否裂损、变形、受热或安装受力。

### 5.3 处理分支

| 确认对象 | 处理内容 | 完成后的验证 |
|---|---|---|
| 接合处密封损坏 | 更换适配密封，核对接触面、位置及固定 | 原位置无新鲜湿漏，复核油位 |
| 管路裂损、压扁或受热异常 | 更换适配管路，恢复走向及隔热支撑 | 无干涉或应力，连接和供回油条件复核 |
| 上方其他部件漏油 | 先处理真实来源，清理流经区域 | 湿痕不再从上方出现 |
| 疑似内部受限或润滑不足 | 专项检查油品、滤清及供回油条件；按对应规范测量 | 保留方法、条件、结果及规范依据 |
| 原因尚不明确 | 继续定位源头，不随机更换密封件 | 下一轮观察能区分来源 |

### 5.4 本地密封要求与使用边界

本地装配图第 I 部分中，1、13 号 O 形环要求更换并用发动机机油润滑。只对图中相应部位使用这一要求，不把机油润滑规则套到冷却液密封或所有增压软管接合面。

油路清洁和密封孔位尤其重要。Garrett 安装说明提醒避免液体密封材料进入油路，并要求按车型规范选用密封和紧固数据。不能用多涂密封胶代替损坏的管口或错误密封件。[来源：Garrett 安装注意事项](https://www.garrettmotion.com/fr/news/newsroom/article/garrett-turbocharger-installation-guide-rules-to-be-strictly-followed/)

### 5.5 涡轮损伤后为什么还要查油路

若只更换受损总成，而供油受限、污染或回油条件未恢复，新件仍可能再次受损。需要把“已经损坏的部件”和“导致损坏的条件”分成两条处理记录；没有测量支持时不编造机油压力合格值。

### 5.6 渗漏、积油与烟雾同时存在时怎样分开定位

先把观察分成三个位置：壳体外部、压气机入口、压气机出口及下游。分别记录旧油膜、新鲜湿痕、液滴、积液以及出现时间；不能把上方流下的油、入口带入的油和内部新增油合成一个“涡轮漏油”结论。

1. 核对机油液位与近期补加量，排除过量加注或记录不一致。对明显积液和伴碎屑的情况先停止运行，保留样本与位置。
2. 外部渗漏从最高新鲜湿点向下追踪；清理一小段便于观察，不先清掉全部路径。重新出现位置能帮助区分供油接头、回油接头和上方其他来源。
3. 对拆下可检查的回油管，查看压扁、折弯、热损伤、接合错位及内部沉积；确认密封未遮挡通道。不可清洁验证或材料受损的管路按适配方案更换，不把松散残渣推回发动机。
4. 同时检查曲轴箱通风连接、膜片/阀及油气分离方向的已有故障。需要压力测量时，用规定接入位置和低压差仪表，记录转速、温度与数值；油盖吸力或手感不能替代曲轴箱压力判据。
5. 供油能力需要测量时，在车辆允许的测试点使用匹配设备并核对油温、转速及规范；不能松开供油管启动来观察喷油大小。

| 证据组合 | 下一步处理 |
|---|---|
| 外部最高湿点在上方其他件，涡轮接合面未复现湿漏 | 处理上游漏点，再观察原流经区域 |
| 油管密封面重复形成新鲜湿漏 | 检查密封、法兰和管体，处理确认对象后原位置复查 |
| 回油受限或通风异常，出口积油 | 先处理已证实的回油/通风条件，再评估残留和本体，不仅更换总成 |
| 供回油条件可靠，仍有重复积油并伴直接损伤 | 保留本体检测证据，进入适配总成或专业修理方案 |
| 只有一次油膜或烟雾记录 | 先补位置、时间和油量变化，不把一次观察升级成内部密封损坏 |

修后将“外部泄漏消失”“积油是否再次增加”“原烟雾是否复现”分别记录。下游已有残留会影响初次观察，但不能把持续烟雾一律解释为残留；出现新积液或异常油耗需要继续查来源。

## 6. TUR-04：冷却液结晶、湿痕与明显泄漏

### 6.1 先区分旧残留和正在泄漏

结晶可能对应以往泄漏或维修残留，也可能是少量渗漏蒸发后的结果。结合清理后是否重新出现、液位是否变化、湿痕起点及管路状态判断；仅凭颜色不能确认液体性质。

检查前让系统充分冷却，不打开仍热且可能带压的冷却系统。需要压力检验时使用该冷却系统的专用方法和参数，不能套用空气通路的检漏压力。

### 6.2 具体检查与处理

1. 观察供液、回流连接及相邻部位，沿痕迹追到源头。
2. 检查管路是否受拉、接头是否偏斜、固定是否缺失，并记录是否近期拆装。
3. 只有旧结晶时，保留原貌后清理并安排复查；没有复发证据不能先判本体内漏。
4. 确认连接泄漏后，在冷却和适当放液条件下处理匹配密封、配合面或受损管路。
5. 恢复连接、冷却液规格与液位，并按对应车辆程序完成加注/排气。
6. 检查冷态及运行后状态；待冷却至规定条件再比较液位，避免把热胀冷缩当成损失。

本地装配图第 I 部分 4 号 O 形环要求更换、用冷却液润滑；与机油管密封的介质不同。若管口本身裂损，仅换 O 形环不能解决。

### 6.3 对应选项的含义

“正常/未见异常”保留观察范围；“结晶或湿痕”首先是定位线索；“明显泄漏”要求优先处理并评估能否运行；“无法检查/无法取得”需写明原因。液位下降但本区域没有定位到漏点，应继续检查其他来源，不能自动归因于涡轮内部。

## 7. TUR-05：排气侧、增压侧与连接松动

### 7.1 先写清连接位于哪里

| 位置 | 关注点 | 对主诉的解释边界 |
|---|---|---|
| 涡轮之前的排气连接 | 接合处积炭、泄漏声、固定和配合面 | 可能影响驱动涡轮的废气条件，需要具体定位 |
| 涡轮之后的排气连接 | 法兰密封、支撑及接头泄漏 | 能解释部分声响和外泄，不能照搬涡轮前泄漏的影响 |
| 压气机出口及增压连接 | 座合、软管、卡箍、密封和定位响应 | 压力侧漏气可能与低增压相符 |
| 隔热板/附件与相邻连接 | 接触、共振、紧固和安装应力 | 可能只有声音异常，并无气体泄漏 |

### 7.2 排气侧泄漏痕迹

记录积炭边缘是否围绕某个接合面，以及是否有可重复的同位置泄漏证据。旧积炭、连接松动和实际泄漏应分别表达。避免用手靠近运行中的高温连接寻找气流。

确认接合问题后，按对应拆装条件支撑排气组件，检查法兰、密封件和紧固件。接触面损坏或位置偏斜时不能单靠紧固补偿。恢复正确对位、密封及支撑后，再检查原位置和邻近连接。

本地图第 I 部分 5 号密封垫要求更换；6 号螺母要求更换并标注 25 Nm。必须先确认是图中同一位置，不能用于所有排气法兰或支架。

### 7.3 增压侧泄漏痕迹

检查软管座合、连接面及固定，定位到软管或管接头后进入相应维修。油迹只提高检查优先级，不单独证明当前漏气。具体接头和检漏步骤见[增压空气通路检查与维修参考](11-增压空气通路检查与维修参考-详细版.md)。

处理后应记录原漏点是否消失；若仍低增压，检查其他已知证据，不因为漏点靠近涡轮就改成“本体已经损坏”。

### 7.4 同时选择不了多种情况时怎样记录

当前 TUR-05 为单选。若排气积炭与增压侧连接松动同时存在，应在选定本轮主要发现后，将另一位置和观察写入备注或独立记录。分析时保留两项事实，不要求一个选项承载全部结论。

## 8. TUR-06：卡滞与异常间隙线索

### 8.1 先明确检查的是哪种活动

“连杆松动”“废气旁通轴活动异常”和“压气机轴系间隙”不是同一对象。记录必须写清部件、方向和检查条件，不能把调节机构卡顿当成叶轮轴承卡死。

无法安全接近时，直接记录受限原因。外部可见检查不要求拆开中间壳体、解除轴端螺母或强行脱开执行器连杆。

### 8.2 为什么手感不能代替间隙判定

BorgWarner 关于滑动轴承涡轮的技术通报区分轴向、径向测量，并说明润滑状态会影响手感。这个原则不能扩展成“任何松动都正常”，也不能把该通报某型号数值套到 DKVB。[来源：BorgWarner S-01-25，Shaft Play in Journal Bearing Turbochargers](https://www.borgwarner.com/docs/default-source/iam/boosting-technologies/shaft-play-in-journal-bearing-turbochargers.pdf?sfvrsn=4356ae3d_0)

需要判定间隙时，应由具备条件的人员按确切总成规范测量，记录测点、方向、润滑状态、读数、单位与允许值来源。本文不编写通用毫米阈值。

### 8.3 选项与下一步

| 选择 | 合理解释 | 下一步 |
|---|---|---|
| 未见相关线索 | 本次允许范围内未观察到明显机械异常 | 结合其余证据；不宣称内部全面合格 |
| 卡滞线索 | 某个部件活动受阻，需要确定对象与原因 | 排除外部干涉；轴系卡滞或擦碰转专项检测 |
| 异常间隙线索 | 有待测量的活动异常 | 明确方向和对象，检查是否伴随接触痕迹 |
| 无法安全接近 | 无有效机械检查结果 | 保留未知，利用其他线索决定是否交接 |

明显擦碰、叶片损伤或卡死时，不再反复转动“磨顺”。涡轮内部修理涉及精密配合及动平衡，应交由具备对应能力的机构；在车上喷清洗剂或敲击轴系不是维修路径。

### 8.4 需要内部测量时，怎样交出可执行的检测任务

要求检测人员先确定总成型号、轴承类型及检查状态，再分别测轴向和径向间隙；报告要列测点、施力方式、是否带油、工具分辨率和对应规范。只有“手摸有一点松”不能用于订件。

委托内容应具体到：“确认叶片是否缺损或与壳体接触；区分轴系间隙与废气旁通轴活动；检查壳体擦碰位置；确认损伤是否需要更换中间组件或总成；核查油液和异物失效线索”。要求返回照片、测量值及处置依据，而不是只接收一句“涡轮坏了”。

若检测证实是外部连接、支架或保持件问题，回到对应外部处理；若证实轴系或叶轮损伤，处理本体的同时追查润滑、异物和下游残留。专业检测的作用是补齐具体证据，不是跳过原因定位。

## 9. TUR-07：啸叫、刮擦声与负荷相关异响

### 9.1 先记录声音条件

记录冷/热、转速、负荷、加速或松油、持续或间歇，以及最明显位置。录音只是辅助，不能根据手机声音直接判轴承损坏。静态没有重现负荷声，也不能据此填写原症状消失。

### 9.2 不同声音怎样分流

| 选择 | 优先区分 | 处理方向 |
|---|---|---|
| 未发现/无 | 本轮是否包含原发声条件 | 未覆盖原工况时保留限制 |
| 啸叫 | 入口受限、增压漏气、排气泄漏与本体声源 | 先查有定位证据的连接，再考虑专项机械检测 |
| 刮擦声 | 是否有叶轮擦碰、碎屑或其他旋转件接触 | 疑似本体接触时停止负荷测试并核查 |
| 异响 | 隔热板、支撑、连杆、排气接触及其他附件 | 用位置与条件缩小范围，不从泛称直接换件 |
| 负荷相关但类型不明 | 声音与目标/实际压力、故障发生时点是否相符 | 在适于运行的条件下采集同步记录 |
| 无法检查/无法取得 | 无法重现、不能运行或记录条件不足 | 说明原因并选择可行的静态检查 |

### 9.3 处理及验证

明确漏点就处理漏点，隔热板干涉就处理其安装，机械接触就转本体检测。修后复检应尽可能覆盖原声响条件，分别记录声音、压力和主诉。声音消失但动力不足仍在，说明解决了一个问题，需要继续剩余方向。

不可在开放进气口旁运行发动机听叶轮声，也不可让驾驶者一边操作记录设备一边进行负荷验证。

## 10. TUR-08：蓝烟、黑烟与其他烟雾

### 10.1 先确定烟雾从哪里出来

发动机舱因油液滴到热表面产生的烟，与排气尾管烟雾分别记录。排气冷凝水汽、蓝灰烟、黑烟及冷却液相关异常不能仅凭一次远距离目测下结论；补充热车后是否持续、液位变化和发生条件。

### 10.2 蓝烟方向

蓝烟提示需要检查机油相关原因，但来源可能在涡轮、曲轴箱通风或发动机内部。优先对照油位记录、入口/出口油迹分布、供回油状况与机械线索。

只有蓝烟，没有本体损伤或油液路径证据时，先定位；蓝烟伴明显积油、叶轮损伤或擦碰时，应提高本体专项优先级并停止不合适的运行。机油消耗只可依据可比测量记录，不用“经常补油”虚构精确数值。

### 10.3 黑烟方向

检查空气供给、燃烧及燃油相关事实，结合空滤、气路、压力可信度和其他动力系统记录。DKVB 是汽油机，不能照搬柴油机的调泵、喷油量或烟度判据。持续明显黑烟不适合继续反复高负荷试验。

### 10.4 其他烟雾或类型不明

先描述颜色、位置、冷热变化及持续性。如果伴随冷却液减少、过热或运行异常，进入相应系统检查；不能只因涡轮带冷却管，就直接判涡轮水道内漏。

### 10.5 处理后的烟雾复核

处理了实际漏油点或受损部件后，仍应确认下游残留污染是否已按适用方法处理。不能把持续烟雾一律解释为“旧油烧完就好”，也不应仅因刚启动有短时变化就立刻认定新件失效。结合液位趋势、新鲜积油、机械状态和原工况逐步判断。

## 11. TUR-09—TUR-10：证据合并与本轮收尾

### 11.1 TUR-09 是综合状态，不是新增测量

当前模板将 TUR-09 定义为由已有记录形成的综合状态，不作为用户再次提交的独立现场观察。本文解释其含义，但不把状态本身当成第二份本体损伤证据。

| 状态 | 应怎样理解 | 本轮建议 |
|---|---|---|
| 暂无支持 | 现有记录未形成指向本体的有效支持，可能仍有未知项 | 沿气路、测量或控制的已有线索继续 |
| 支持较弱 | 有可疑现象，但来源或关联仍不明确 | 选择最能区分原因的一项检查 |
| 多项独立线索支持 | 不同来源事实相互吻合 | 安排针对性专业确认及维修准备 |
| 事实冲突 | 位置、时间、工况或解释存在矛盾 | 核查冲突来源，保留不同轮次的事实 |

同一片油污在入口题和烟雾备注里重复描述，不算两项独立证据。没有记录不是反证；外观正常也不否定未覆盖工况下的异常。相反，直接可见严重损伤不需要等待系统达到某种数量条件才停止运行。

### 11.2 TUR-10 收尾选择

- **返回控制方向复核**：本体直接证据不足，而执行器、反馈或压力信号有明确待查方向。说明具体回到哪个问题，不泛称“全部重查”。
- **转专业检测**：需要内部测量、损伤评估、拆检或总成维修。写明对象、已有证据及待回答问题，而不只写“交给专业人员”。
- **转其他动力系统**：压力已恢复但主诉仍在，或现有失火、燃油、排气受阻等事实更有解释力。保留已完成的本体检查范围。
- **安全停止**：存在继续运行会扩大损伤的具体发现。写明停止的是启动、负荷测试还是某项拆检，以及恢复前需要解决什么。

收尾选项表示本轮去向，不等同于修复完成或车辆可交付。

## 12. 维修路径：从外部处理到总成更换

### 12.1 可以明确到对象的外部处理

| 已确认异常 | 具体工作 | 不能遗漏 |
|---|---|---|
| 隔热板或支架松动 | 恢复匹配固定件、位置和间隔 | 检查被磨损或受热的邻近管线 |
| 油路接合密封问题 | 处理匹配密封与接触面，恢复管路自然位置 | 油位、供回油条件及新鲜泄漏复核 |
| 冷却管接头泄漏 | 处理密封或受损管路，恢复加注与排气 | 冷态液位和运行后复查 |
| 增压接口座合/密封问题 | 按实际连接结构恢复或更换受损件 | 原漏点和压力表现分别验证 |
| 排气接合问题 | 检查法兰、密封、紧固件及支撑 | 安装应力、邻近部位和原声音 |
| 入口异物来源明确 | 处理入口路径，评估叶轮与下游污染 | 不遗漏碎屑及发动机吸入风险 |

### 12.2 何时进入总成或内部专业处理

确认叶片损伤、内部接触、轴系卡滞、经适用规范测量的异常间隙，或确认不可通过外部连接维修恢复的本体损伤时，进入专业修理/适配总成方案。选用何种方案应结合损伤范围、可修复性、配件与检测能力。

更换总成之前，应有“为什么需要更换”的具体依据，并查清是否存在异物、润滑、排气或控制方面的致损条件。不要把“气路检查没发现”作为本体损坏的唯一证明。

### 12.3 总成处理的工作顺序

以下是维修组织顺序，并非从零开始的全套车型拆装工艺：

1. **保存处理前资料。** 保留故障、位置照片、液位/油耗信息、压力及声音表现；记录已经确认和仍待确认的项目。
2. **确认部件适配。** 按 VIN、发动机和原总成标识核对替换关系、接口、执行器配置及需要的密封件。不能只凭“探岳 2.0T”选件。
3. **准备拆装条件。** 按车型流程完成必要前置拆卸、液体回收和组件支撑；不让总成悬挂在油管、冷却管或连杆上。
4. **分区检查拆下部件。** 留存本体、供回油、冷却连接和气路内的异常；不要先清洗掉所有根因线索。
5. **处理污染和失效来源。** 发现碎屑或积液时，按污染范围检查下游管路、中冷器及必要的发动机部位；不能未经检查直接复用受污染组件。
6. **恢复安装条件。** 处理接触面、支撑和密封，确认油液通道洁净、无堵塞或变形，按确切部位要求紧固。
7. **按匹配程序完成润滑准备。** 具体预润滑、建立供油及首次启动步骤使用车辆和替换件要求；不能装完立即高转速试车。
8. **恢复系统。** 清点封堵件，连接进排气、电气、油液和冷却回路，恢复隔热与支撑；按要求加注及排气。
9. **完成必要设置。** 若所用总成/执行器配置要求基本设置，进入匹配程序，保存完成、失败或中止的真实结果。
10. **分阶段复检。** 先安装和液体、再静态运行、最后在具备条件时验证原工况；发现异常及时回到对应分支。

Garrett 的安装流程强调油路通畅、预润滑和初次运行时的泄漏检查。其通用页面中的启动时间、怠速时间及其他结构操作未直接用作 DKVB 固定要求。[来源：Garrett 安装步骤](https://www.garrettmotion.com/fr/news/newsroom/article/garrett-turbocharger-installation-guide-steps-to-proper-turbo-installation/)

### 12.4 本资料不提供的内部修复动作

叶轮打磨、轴端螺母拆装、转子动平衡、轴承配合加工和壳体修复不能用普通外观检查替代。需要这些操作时，交接内容应包含明确损伤与检测目标，而不是用一段未经核对的步骤指导现场试修。

同样，不通过随意改变 V465 推杆长度、旁通预紧或控制参数掩盖机械和泄漏问题。调节机构具体分支见[增压调节机构检查与维修参考](15-增压调节机构检查与维修参考-详细版.md)。

### 12.5 总成处理前后的现场工作清单

把工单拆成六个可以核对的阶段，避免“换涡轮”三个字遗漏配套处理：

1. **确定更换对象。** 保存总成铭牌、VIN、执行器配置和失效照片；按适配清单准备密封、紧固件及需要更换的管路。只确认车型名称不够。
2. **拆前处理连接。** 拍照并标记电气、油路、冷却及气路去向；冷却后回收需要排放的液体，按车型步骤释放前置组件并独立支撑总成。解除连接后使用洁净保护盖，清点数量。
3. **检查导致旧件失效的条件。** 分别查看供油污染与受限、回油变形、通风异常、上游异物、下游碎屑和安装应力。发现叶轮缺损时，不把未检查的中冷器和管道直接接回。
4. **恢复配合与固定。** 检查法兰、螺纹、支撑和管路是否能自然对位；按具体部位更换密封与一次性件，分清油路、排气和支架的紧固要求。不能以一项通用扭矩代替整套紧固表。
5. **完成润滑及系统准备。** 使用适配机油和替换件安装说明要求的预润滑方法，核对供回油畅通、恢复液位和冷却排气。首次建立润滑的方式和启动条件要与车辆匹配；不能借用其他发动机的固定起动秒数或随意断开某个传感器阻止启动。
6. **先静态后运行。** 清点并移除所有保护盖、工具；确认连接、油液和必要设置后启动。先观察泄漏、异常声音与报警，合格后才安排原工况验证。记录每次发现的问题和处理，不能用“新件已装”结单。

Garrett 的安装指南强调新件安装前确认油路和润滑条件，安装后观察泄漏；本文采用这些工作环节，未采用其通用页面的启动时间作为 DKVB 要求。[Garrett 安装指南](https://www.garrettmotion.com/knowledge-center-category/turbo-replacement/part-2-garrett-turbocharger-installation-guide/)

### 12.6 换后不改善时先回查什么

若出现新泄漏，优先核对本次拆动的密封、接合与管路应力；若反馈异常，核对零件适配、插头和设置结果；若同样异响仍在，对照原声源是否其实来自排气连接或附件；若仍冒烟，比较新积液、油耗与下游残留，不直接再次更换。新出现的故障与原故障分别记录，有助于识别安装问题和未解决的根因。

## 13. 处理后的独立复检

### 13.1 装配与静态检查

核对本次拆动的连接、密封、固定、隔热板、线束和支撑。检查有无封堵物遗留，进排气是否完整恢复，液位及加注条件是否满足。总成已安装、连接已恢复、设置已完成应分别记录。

### 13.2 运行与泄漏检查

具备启动条件后，按适用首次运行程序观察油液、冷却液、排气与增压连接，以及声音和报警。发现新鲜泄漏、异常接触声或运行异常时停止对应试验，先查明原因。

对于原来只有连接泄漏的维修，重点验证原位置及相邻部位。对于本体更换，还要核对造成旧件损坏的条件是否已经处理；新件能运行不能证明根因已经消除。

### 13.3 原工况与压力复检

使用可信、可比较的数据记录转速、负荷、驾驶请求、目标压力和实际压力，确认单位以及绝对压力/表压口径。详细采集方法见[增压压力测量检查与维修参考](14-增压压力测量检查与维修参考-详细版.md)。

负荷验证由合适人员在安全条件下完成，驾驶与数据记录分工。尚有严重机械、润滑或冷却异常时不进入该阶段。原故障只在负荷下出现，怠速无报警不足以证明问题消失。

### 13.4 结论怎样写

| 新取得的结果 | 合理结论 | 下一步 |
|---|---|---|
| 原漏点消失，声音和原主诉改善 | 本次处理有对应效果 | 写清验证工况和未覆盖范围 |
| 外部泄漏消失，仍低增压 | 已解决泄漏，动力问题仍待定位 | 根据气路、压力和控制记录继续 |
| 异响消失，压力未恢复 | 声音问题改善，不等于增压问题解决 | 查剩余有效线索 |
| 压力恢复，原主诉仍在 | 增压表现改善，存在其他动力方向 | 转查与残余主诉相关的记录 |
| 更换后仍出现新鲜油液或持续烟雾 | 未完成原因闭环 | 复核油液路径、残留污染和发动机侧问题 |
| 未取得可比工况 | 实际处理已实施，效果待验证 | 保留待复检状态 |
| 只有清码或设置完成 | 尚无完整修复效果证据 | 补充运行及主诉复检 |

### 13.5 推荐记录格式

**处理前：** 异常对象、位置、条件、已保存的直接证据。  
**实际处理：** 处理了哪些部件与致损原因，实际更换/恢复了什么。  
**新复检：** 本轮工况、泄漏、声音、液位、压力和主诉的新结果。  
**当前结局：** 已验证部分、仍存在的问题、下一步对象及无法完成原因。

维修建议不能自动进入“实际处理”；处理前数据不能复制为处理后结果。需要多轮维修时分别保存，保留第一次处理取得的部分改善。

## 14. 常见情况组合与处理顺序

以下为条件分支，用于理解不同记录怎样改变建议；不表示某个病例已经发生这些情况，也不预设复检结果。

### 情况一：加速啸叫，涡轮出口连接有明确漏点

**判断：** 优先处理已定位的压力侧连接。啸叫与低增压可与此相符，但不足以指向内部损伤。

**处理：** 核对连接结构，检查管口、软管和固定件；材料完好则恢复正确座合与紧固，损坏则处理对应件；恢复支撑后重新检漏。

**复检：** 原漏点、声音、压力和主诉分别验证。漏点消失但低增压仍在，再按剩余线索继续，不直接换总成。

### 情况二：隔热板松动，有金属振动声，未见其他本体线索

**判断：** 已有具体外部声源，不宜把泛称“异响”升级为轴承故障。

**处理：** 检查隔热板、支座和紧固件，恢复位置及间隔，处理附近已磨损部位。

**复检：** 对比原声响条件。若声音消失而动力问题仍在，保留隔热板处理结果并继续动力方向。

### 情况三：入口有薄油膜，无可靠油耗记录，也未见叶片损伤

**判断：** 油膜是线索，尚不能确认涡轮内部漏油。

**处理：** 记录油膜位置，核对通风和上游来源，建立可比较的液位/里程记录；按现有主诉选择必要检查。

**复检：** 观察是否持续新增、是否伴随烟雾或其他机械证据，不编造允许积油量。

### 情况四：蓝烟、异常积油，同时存在回油管变形

**判断：** 回油条件是明确需要处理的对象，同时需评估本体是否已经受损。

**处理：** 停止不适宜的运行，查变形原因并恢复适配管路；核查通风、液位及下游污染，按机械证据决定是否进一步检测总成。

**复检：** 不能只看管路外表不漏，还要比较新鲜积油、烟雾及液位趋势。

### 情况五：叶片缺口、入口异物与刮擦声同时存在

**判断：** 已有直接损伤证据，应停止运行并进入本体及污染范围检查。

**处理：** 保留异物和损伤记录，查明进入路径，评估总成与下游；不能打磨叶片后继续使用，也不能只换总成不查碎片。

**复检：** 来源已处理、污染范围已处理、安装及润滑准备完成后，再按阶段验证。

### 情况六：供油接合处新鲜滴油，但没有内部损伤证据

**判断：** 优先处理定位明确的外部泄漏，并评估油量损失和润滑影响。

**处理：** 查密封、接触面和管路；若油液接近高温部位，先停止运行。按损坏对象修复，不因位置在涡轮旁就更换总成。

**复检：** 原位置干燥、液位稳定与有无异常声音分别确认。

### 情况七：冷却管接头有结晶，清理后未再次湿润

**判断：** 本轮尚未确认持续泄漏，不能以旧结晶认定本体内漏。

**处理：** 核对维修史和液位记录，检查接头与管路状态；有需要时按冷却系统专项方法检测。

**复检：** 保留观察时间和冷热条件；液位继续下降则扩大真实来源检查。

### 情况八：排气接合处积炭，同时存在固定松动

**判断：** 应优先确认接合泄漏及其具体位置，区分涡轮前后。

**处理：** 检查法兰、密封和紧固支撑，恢复正确对位；不要只清理积炭或盲目加力。

**复检：** 原连接处、声音和运行表现分别检查，不能把所有排气泄漏都写成同一种低增压原因。

### 情况九：有“异常间隙线索”，但未注明对象与方向

**判断：** 信息还不足以作总成判废，可能把连杆活动与轴系活动混在一起。

**处理：** 先补充检查对象、方法和条件；需定量结论时按总成规范测量。若伴明显擦碰或叶片损伤则直接提高专项优先级。

**复检：** 留存实际测量和依据，不用手感替代毫米读数。

### 情况十：本体外观未见异常，V465 反馈异常，压力仍低

**判断：** 当前控制方向更有针对性，外观正常并不等于内部已经排除。

**处理：** 返回调节机构，核对电气、动作、连接和适用设置；避免从外观无异常跳到预防性更换涡轮。

**复检：** 处理后以新的反馈、压力和主诉记录评价效果。

### 情况十一：黑烟伴失火或燃油线索，压力信号又不可信

**判断：** 不宜用失真的压力差支持本体结论，也不能把黑烟全部归因于涡轮。

**处理：** 按明确故障分流到压力可信度及相关动力系统；持续异常烟雾时停止负荷验证。

**复检：** 待数据与运行条件恢复，再判断是否仍有本体专项必要。

### 情况十二：更换后仍有同样异响或烟雾

**判断：** 需要核查原始定位、安装、润滑与污染处理，不能只重复更换。

**处理：** 对比声音位置、液体路径和旧件损伤报告；检查连接、支撑和致损原因是否遗漏。

**复检：** 用新的直接证据缩小范围，不能默认残留污染，也不能未经确认认定新件质量问题。

## 17. 与其他区域联合分析时怎样使用

| 本体区域发现 | 其他区域发现 | 本轮优先方向 |
|---|---|---|
| 只有啸叫，未见直接损伤 | 气路有明确漏点 | 先处理该漏点，保留声音与压力复检 |
| 外观未见异常 | 压力信号跳变、静态不可信 | 先恢复压力判断依据 |
| 无直接轴系证据 | 连杆脱开或执行器动作异常 | 调节机构专项 |
| 叶片损伤或明显擦碰 | 上游导管破损/异物 | 本体损伤与异物来源共同处理 |
| 油液异常 | 曲轴箱通风或油路存在明确问题 | 油液路径及本体受损程度联合检查 |
| 压力恢复后仍动力不足 | 失火、燃油或排气线索 | 转向与残余主诉相关的动力系统 |

分析应先提出当前最有依据的处理对象，再说明确认方法、实际处理和复检要求。无需复述全部章节，也不要求把所有未知项变成维修前置条件。

建议输出可采用：**当前判断 → 先查/先处理什么 → 怎样确认有效 → 无效时转向哪里。** 引用位置和问题 ID 用于追溯，不应代替明确的部件名称和动作。不同时间取得的记录应按先后解释，不能将维修前异常与维修后改善当成互相冲突。
