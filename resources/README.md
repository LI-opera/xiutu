# 版本化资源

- templates/tayron-v2：独立模板 JSON、适用关系和资料版本清单。
- knowledge/tayron：资料清单实际引用的 Markdown 原文，供显式登记到数据库。
- legacy/：隔离历史回归需要的合成资料样本。

这些是源码/配置资源，不是当前病例库，不包含现场记录、模型凭证或调用账本。模板 JSON 中部分历史来源位置原样保留以保持已发布内容哈希；运行时静态图片来自 frontend/public，初始化资料来自本目录，不要求这些历史路径实际存在。

原始厂家 PDF、完整下载资料目录、数据库备份和本机模型不上传。当前仓库为私有，不附加未经确认的开源许可。
